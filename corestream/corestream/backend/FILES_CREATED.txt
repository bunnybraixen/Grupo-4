AUTENTICACIÓN Y MIDDLEWARE (2 archivos, 8 funciones)
====================================================

14. app/middleware/__init__.py
    - Exporta funciones de autenticación
    - Lista __all__ completa

15. app/middleware/auth.py (450+ líneas)
    Funciones:
    - hash_password(password) -> str
      * Hash seguro con bcrypt
      * Sin texto plano en BD
      * Verificación sin timing attacks
    
    - verify_password(plain, hashed) -> bool
      * Comparación segura de contraseñas
    
    - create_access_token(data, expires_delta) -> str
      * Genera JWT de acceso (corta duración)
      * Incluye exp claim
      * Firmado con SECRET_KEY y ALGORITHM
    
    - create_refresh_token(data) -> str
      * Genera JWT de refresco (larga duración)
      * Para obtener nuevos access tokens
    
    - verify_token(token) -> TokenPayload
      * Decodifica y valida JWT
      * Verifica firma y expiración
      * Retorna TokenPayload
    
    - get_current_user(credentials) -> TokenPayload
      * Dependencia FastAPI
      * Extrae token del header Authorization
      * Valida autenticación
      * Retorna datos del usuario
    
    - require_role(required_roles) -> factory
      * Factory que crea dependencia de autorización
      * Verifica que usuario tiene uno de los roles requeridos
      * RBAC (Role-Based Access Control)
    
    - Constantes:
      * pwd_context: CryptContext con bcrypt
      * security: HTTPBearer para extracción de tokens
