Proyecto: CoreStream

- Descripción:
CoreStream es una plataforma web de inteligencia operacional para la gestión y control de proyectos de desarrollo de software.
Está dirigida principalmente a equipos de desarrollo de software, líderes de grupo y administradores, permitiendo organizar y controlar el trabajo mediante una jerarquía de:

Aplicaciones → Épicas → Tickets → Subtareas

El proyecto corresponde a una continuidad de CoreStream 1.0, por lo que el objetivo es incorporar nuevas funcionalidades y mejoras para evolucionar la plataforma hacia una herramienta más completa y competitiva de gestión de proyectos.

- Tecnologías utilizadas:
Frontend
Vue 3 — Framework para el desarrollo de la interfaz web.
TypeScript — Lenguaje utilizado para el desarrollo frontend.
Vite — Herramienta de construcción y desarrollo.
Pinia — Gestión del estado de la aplicación.
Vue Router — Gestión de navegación.
Axios — Comunicación con la API REST.
Tailwind CSS — Estilos e interfaz.
Vue Draggable — Funcionalidad de arrastrar y soltar.
Vue-i18n — Internacionalización.
Chart.js / ApexCharts — Visualización de datos y métricas.
jsPDF — Generación de reportes PDF.

Backend
Python — Lenguaje principal del backend.
FastAPI — Framework para construcción de la API REST.
Uvicorn — Servidor ASGI.
Pydantic v2 — Validación y manejo de datos.
SQLAlchemy — ORM para interacción con la base de datos.
asyncpg — Conector asíncrono para PostgreSQL.
Alembic — Gestión de migraciones de base de datos.
Redis — Cache, pub/sub y soporte para tareas.
ARQ — Cola de tareas asíncronas.
WebSocket — Comunicación en tiempo real.
JWT — Autenticación.
bcrypt — Protección de contraseñas.
RBAC — Control de acceso basado en roles.

Base de datos
PostgreSQL

Testing
pytest
pytest-asyncio
Vitest
Cypress
DevOps / Cloud
Docker — Contenedorización de la aplicación.
Git — Control de versiones.
GitHub — Repositorio y colaboración.
GitHub Actions / CI/CD — Automatización de integración y despliegue.
Vercel — Despliegue del frontend.
Railway — Despliegue del backend, PostgreSQL y Redis.
